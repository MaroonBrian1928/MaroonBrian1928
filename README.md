### hey, I'm Brian 👋

I'm in Minneapolis and build stuff in Rust, Python and TypeScript.

**Podcasts**
- [Podly](https://github.com/podly-pure-podcasts/podly_pure_podcasts): ad-block for podcasts. I help maintain it.
- [podly_pure_podcasts_x](https://github.com/MaroonBrian1928/podly_pure_podcasts_x): my performance fork of Podly. The hot paths are in Rust, so it idles on about a fifth of upstream's memory and serves feeds hundreds of times faster. It also adds speaker diarization and word-level ad cuts.
- [parakeetX](https://github.com/MaroonBrian1928/parakeetX): an OpenAI-compatible transcription API on NVIDIA Parakeet, with word timestamps and diarization.
- [InaFastAPI](https://github.com/MaroonBrian1928/InaFastAPI): a speech/music/noise segmentation API that helps my Podly fork spot ads.

**Other stuff**
- [lunatune](https://github.com/MaroonBrian1928/lunatune): one command that tunes a Mac for Moonlight game streaming over Wi-Fi to cut the stutter, then puts everything back when you quit.
- [RunningBuddy](https://github.com/MaroonBrian1928/RunningBuddy): a local-first training dashboard with Strava sync and LLM coaching.
- [brians-skills](https://github.com/MaroonBrian1928/brians-skills): skills for Claude Code.
